## 5. 切换与回退（草稿，待按 CLI 实际输出核定）

1. `python maintain.py inspect --json` → 必须 `status=compatible`；
2. `python maintain.py backup --json` → 产出独立备份目录与 manifest（含 sha256）；
3. `python maintain.py verify --json` → 备份复验 `ok`；
4. 切入口（用户决定）；
5. 回退：用备份目录替换库文件，`git checkout` 回旧分支。
