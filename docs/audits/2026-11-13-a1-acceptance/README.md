## 2. 已确认的改善

1. 两个独立文件具有相同字节时，现在保留不同逻辑资产；复制件可独立演进，旧计划仍能读取。上轮最直接的 AR3-01 反例已过。
2. `expected_binding_absent`、旧内容键和调用者事务开始发挥作用。不同内容的陈旧请求、autocommit 写入和中途失败都有拒绝或回滚覆盖；增加了 `apply_archive_resolutions` 专用 writer 命令。
3. 新增显式接受事件，当前绑定引用被接受的检查。仅追加 changed/missing/unreadable/取消/旧根诊断，不再自行授权替换；AR3-03 原始反例关闭。
4. 实际观察的根版本不能被候选重标，旧快照回执与新观察的 snapshot/mtime 错配已拒绝。AR3-04 的两个具体错配修好了；完整应用事务仍未完成。
5. ASCII 大小写别名在接受层能够复用，不再直接报原来的不可变资产冲突。计划保存与中文混合字符别名尚未统一，见 AR4-05。
6. shared writer 的 `LibraryBusyError` 已适配成 `ArchiveLibraryBusyError`；AR3-10 修复及相关回归通过。
7. 上轮 AR3-07 的状态绕过、AR3-08 的 WAL busy 检查没有被本轮撤销。现有协议、迁移和 WAL 回归通过；本轮未重复上轮全部长读快照脚本，不能扩大为所有故障已覆盖。
