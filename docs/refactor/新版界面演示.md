# 新版界面演示

双击项目根目录 [预览新界面.bat](../../预览新界面.bat)。它与正式 [启动.bat](../../启动.bat) 使用同一份已验收代码，通过 `--demo` 选择离线演示；没有另一套会悄悄落后的前端副本。复用已有解释器，无需安装环境。

演示资料位于项目 `.runtime/offline_demo/`，与真实授权、下载库分开。示例来源提供生成的小 PNG，可体验关注历史/新作、搜索、排行榜、指定画师、推荐、组合筛选、任务、名单和设置。演示不访问 Pixiv；首次打开无任务时显示空状态。

保存位置的「选择…」使用系统文件夹窗口，名单/日志导出使用「另存为」，画师可从 UTF-8 文本导入。取消弹窗不修改设置。若明确选择项目外位置，示例文件会写到选中的位置；这个操作同样是真实的本地文件保存。

正式运行使用「启动.bat」，以原图和全部图片页进行收集；打开窗口不自动联网。演示的模拟账号、计数和图片不代表真实下载结果。五套旧 `.runtime/ui_review_*` 包及数据已进入 [2026-10-24 归档](../../../_archives/jpgpng_tidy_20261024/README.md)，清单保留原始路径和摘要；当前两个入口不再引用它们。

使用方法见 [使用说明](../../使用说明.md)，版本证据见 [重构进度](REFACTOR_PROGRESS.md)。
