## 保留的视觉语言

| 要素 | 实施要求 |
| --- | --- |
| 主面 | 大面积白色，外围或少量分区用很浅的冷灰；内容自然展开 |
| 颜色 | 冷灰文字/细线与清爽蓝色强调，浅蓝用于续跑区、选中行和少量底板 |
| 导航 | 顶部横向文字导航，当前项蓝字和细下划线；宽窗口与品牌同一行，窄窗口合理换行 |
| 文字 | 品牌、页标题、区块标题、说明、数字有清楚层次；页标题常规字重，避免每处都加粗 |
| 续跑主区 | 浅蓝灰底、细蓝上边线、少量错位底板；主按钮与当前任务信息形成一个操作区 |
| 阴影与层次 | 用户明确认可少量合适阴影；用于主操作区、按钮或弹出选项的轻投影，配合细边框和错位底板，普通列表保持平整 |
| 首页信息 | 清晰的本批记录数字、简短说明和分隔线，右侧下载选项与正文之间留白/细分隔 |
| 任务页 | 白底行式任务列表，薄分隔、轻选中底色、清晰状态与就地操作，下方内嵌详情/最近活动 |
| 密度 | 保留呼吸空间，同时让主要操作和信息处于可用窗口内；布局可按真实功能重排 |
| 日志 | 默认简短/折叠，展开不破坏主要操作区；清空、暂停显示和跟随的原有行为要求保留 |

来自已有原始设计 SVG 的起始色值：主面 `#FFFFFF`、外围 `#F2F5F6`、主字 `#202B33`、次字 `#596A75`、主蓝 `#287EAE`、细线 `#DCE4E8`、边框 `#D8E1E5`、续跑底 `#F7FAFC`、错位底板 `#E8F1F6`。它们是落实截图的起点，微调需对照真实截图，不能再另换整套配色。

功能和性能要求不变：原图质量第一，性能第二，易用与美化随后；下载主流程不增加预览图。优先复用现有 Python 环境、使用相对业务路径，避免为美化另建专用环境或独立 Node 运行环境。用户允许合理的大幅重构、专门编写美化代码，也接受确有收益的少量依赖（少于十个只是可接受范围，不是目标数量）。依赖须同时评估传递依赖、体积、启动/内存/CPU开销和维护成本。之前“只用 Tk/ttk”“不增加任何美化依赖”“Canvas 只能画少量装饰”的表述属于过度限制，撤回为非用户要求。具体技术依据实际效果与测量选择；文字可读、键盘可操作、状态可信、关闭可安全收尾等要求保持。

## 复核方式

每轮提供实际窗口的关注页和任务页，分别对照上面两张基准检查主面/配色、导航、文字层级、续跑区/列表、留白与操作位置；再检查窄窗口和日志展开。布局变化须服务真实功能，样式判断以本基准为准，不再用“原生工具风格”替代用户认可的方向。
