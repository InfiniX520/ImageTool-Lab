# JpgPng

用于逐步收藏 Pixiv 关注画师的历史作品，也支持关注新作、指定画师、搜索、排行榜、推荐和组合筛选。默认保存原图和全部图片页；界面只显示文字和记录，不请求缩略图或头像。

双击项目根目录的 **[启动.bat](启动.bat)** 打开正式界面。沿用工作区已有 Python 环境和已有授权，无需安装新环境、Node 或界面依赖。程序打开后保持空闲，点击开始、继续或校验账号才会访问 Pixiv。

日常操作见 **[使用说明](使用说明.md)**；账号整理见 **[CLI 说明](ORGANIZER_CLI.md)**。找文件用 [项目目录说明](docs/PROJECT_LAYOUT.md)，查计划和记录用 [文档导航](docs/README.md)。

## 常用操作

1. 在「关注下载」选择「历史作品」，设定本批最多新增作品数；需要时勾选最低收藏、排除 AI，可以叠加。
2. 点击保存位置旁的「选择…」，用系统窗口选择文件夹。开始后可随时暂停，重启后在「下载任务」选择原任务继续。
3. 「查看本批名单」说明完成、跳过、过滤、未知和失败原因；「下载记录」查询累计成果，并通过「导出记录」另存为 Markdown。
4. 「其他来源」提供搜索、排行榜、指定画师、推荐和组合筛选；附加条件、原图交付和名单使用同一套规则。

批次数量、画师数和查询请求数是不同的预算。预算用完会保存位置并暂停，表示这一批结束，不表示关注画师已经收全。字段无法确认、类型不支持或图片未完整交付会单独记录原因。

## 入口

| 入口 | 用途 |
| --- | --- |
| `启动.bat` | 新版正式下载器，使用项目业务资料 |
| `预览新界面.bat` | 同一界面的离线演示，生成少量样本图片，不读取真实授权 |
| `启动.bat --legacy` | 保留的旧版入口，使用旧记录；请先关闭新版 |
| `启动.bat --help` | 查看启动参数，不联网 |
| `organize.cmd` | 独立关注整理 CLI，供 AI 盘点、实际看图及受控分组；见 [操作说明](ORGANIZER_CLI.md) |

启动器通过项目或上级 `.venv-path` 查找已有解释器，并设置 `PYTHONNOUSERSITE=1`。项目内的数据路径与终端当前目录无关；外部输出目录通过本机映射保存。环境说明在 [工作区文档](../环境说明.md)，不在本项目重复安装依赖。

## 数据与恢复

| 位置 | 内容与处理 |
| --- | --- |
| `downl_Pixiv/` 或你选择的目录 | 原始图片，属于业务数据 |
| `download_logs/library.sqlite3` | 新版任务、断点、页级成果与名单的统一账本 |
| `download_logs/` 中的三个旧库 | 原件保留，旧版继续使用；本次没有导入或双写 |
| `config/collection_v2.json` | 新版偏好，沿用迁入的合法旧设置 |
| `config/output_roots_v1.json` | 选择外部目录后生成的本机位置映射 |
| `pixiv_config.json`、`www.pixiv.net_cookies.txt` | 已有账号资料，禁止公开；新版授权更新仅在明确操作时保存 |
| `runtime_logs/` | 程序诊断日志，界面日志和文件日志分别有容量限制 |
| `record_backups/` | 版本切换与业务记录备份，保留恢复用途 |
| `organizer_data/` | 独立整理账号绑定、关注快照、审阅与操作记录；属于业务资料，不能当缓存删除 |
| `.runtime/offline_demo/` | 离线演示资料，与真实库分开 |

本次采用新账本，不根据旧库或相同文件大小推断图片已经验证。因此旧下载记录不会自动出现在新版累计历史中，旧图可能重新下载；旧文件、旧记录和备份均保留。目标路径已有未核验文件时会报告冲突，不直接覆盖。

移动项目时先关闭程序，再一起保存新账本、配置和图片。外部磁盘目录需要在新机器重新选择；不要只搬一个正在使用的 SQLite 文件。回退步骤见 [使用说明](使用说明.md#备份与回退)。

## 能力边界

图片按来源提供的原始字节保存，不转码、不压缩。校验包含传输长度、文件格式结构和本地摘要；不是全像素深度解码，也不是与服务器公布摘要独立对照。动图打包作品等暂不支持的类型会明确标记，不算下载成功。

组合筛选计算每个来源已查询范围的交集；有候选与请求上限，不能证明全站没有更多符合条件的作品。账号画师分组整理通过独立 [organize.cmd](ORGANIZER_CLI.md) 使用：E1-2 工具已发布，正式分类小样和分批整理尚未完成；下载器不会自动触发分组或样图请求。

## 维护

源码在 `core/`、`gui/`、`utils/` 和 `organizer/`，测试在 `tests/`。下载器 P0—P8 和独立 CLI E1-2 已交付；画师分类小样 E1-3、分批整理 E1-4 待实施。最新阶段以 [重构进度](docs/refactor/REFACTOR_PROGRESS.md) 为准，`TASK_PLAN.json` 的七月阶段保留作历史。

本地测试、截图及回执放在工作区 `.runtime/`；过期界面包、中间副本和旧清理脚本已归入 [2026-10-24 整理档案](../_archives/jpgpng_tidy_20261024/README.md)。每阶段最终候选、原始基线和验收报告保留原位。已有未提交修改保留，不能用清理命令重置工作树或删除业务目录。

离线回归使用工作区解释器。Windows 上此环境的 Tk 多窗口测试需关闭 pytest 文件描述符捕获（`-s`），将命令整体输出重定向到报告目录；不要把捕获相关的 Tcl 故障当作缺环境而重新安装。
